# 후기씨앗

**AI 글은 많아도, 내 경험은 나만 써요.**

체험단·맛집·제품을 다녀온 날, 질문에 답하며 내 경험을 10분 만에 정리하는 안드로이드 앱이에요.
정리한 기록과 사진은 내 구글 드라이브에 가게별 폴더로 저장되고, 블로그 글을 쓸 때 꺼내 써요.

- 홈페이지: https://hugissiat.com
- 앱 소개: https://app.hugissiat.com
- 구글 플레이(비공개 테스트 중): https://play.google.com/store/apps/details?id=com.portpapa.hugissiat
- 사용설명서·질문: 디스코드 https://discord.gg/dKZhZNbCp4
- 문의: hello@hugissiat.com

## 할 수 있는 것

- **링크 하나면 시작**: 네이버 지도에서 가게를 공유하면 주소, 영업시간, 메뉴판이 들어와요. 스마트스토어, 쿠팡 제품 링크도 돼요.
- **질문에 톡톡, 10분이면 끝**: 누구랑, 왜, 주차, 응대, 아쉬운 점까지 고르기만 하면 돼요. 별점은 0.5점 단위로, 현장 메모는 말로 남겨요.
- **일정과 마감도 함께**: 갈 곳 목록과 달력, 후기 마감 3일 전과 전날 알림, 협찬 금액·원고료 월별 정산, 홈 화면 위젯이 있어요.
- **쓸수록 자라는 내 정원**: 블로그에 올릴 때마다 새싹이 자라고, 한 달에 4편을 발행하면 그 달의 꽃이 펴요.
- **완성하면 드라이브에 저장**: 기록과 사진이 구글 드라이브에 가게별 폴더로 저장돼요. 카카오톡이나 메일로 보낼 수도 있어요.

## 이 저장소

- `index.html`: 앱이 여는 화면이에요. 화면 수정은 앱 업데이트 없이 바로 반영돼요.
- `android/`: 안드로이드 앱이에요. 위젯, 알림, 구글 드라이브 저장을 맡아요.
