# 체험단 경험 메모

체험단 다녀온 뒤, AI로 후기를 쓰기 **전에** 내 경험을 정리하는 페이지예요.
선택지를 누르고 짧게 적으면 AI에 바로 넣을 수 있는 `.md` 파일로 정리돼요.

- 페이지: https://portpapa.github.io/hugissiat/
- 폰에서도 그대로 쓸 수 있어요.

## 어떻게 쓰나요

### 1. Aside가 있으면 (자동)
1. Aside에 `chehumdan-memo` 스킬을 설치해요.
2. 체험단 업체의 네이버 플레이스 링크를 보내요.
   예: `체험단 메모 https://naver.me/xxxxxxx`
3. Aside가 플레이스 정보(메뉴·가격·영업시간·편의시설·방문자 키워드)와
   블로그 리뷰 추천순 상위 5개(직접 방문한 후기만)를 읽고,
   남들이 말한 포인트를 선택지로 만들어 **폰에서 여는 링크**를 줘요.
4. 링크를 카톡 "나와의 채팅"이나 텔레그램으로 폰에 보내서 열어요.

### 2. Aside가 없으면 (직접 입력)
위 페이지 주소를 그냥 열면 돼요. 플레이스 정보 없이 선택지와 직접 입력으로 정리해요.

## 쉽게 쓰기 (기본)
질문이 한 화면에 하나씩 나와요. 탭하거나 말로 한 줄 남기면 끝이에요(2~3분).
누구랑 → 왜 → 남들 후기 확인 질문 3~4개 → 먹은 메뉴 → 메뉴별 한마디 → 동행자 반응 → 아쉬운 점 → 재방문 → 자유 메모 순서예요. 모르는 건 건너뛰면 돼요.

## 자세히 쓰기 (선택)
1. **캠페인 가이드**: 제공 내역, 필수 키워드, 필수 사진, 미션, 마감일, 대가 표기 문구를 직접 입력해요.
2. **내 경험 고르기**: 누구랑 왜 갔는지, 주차, 분위기, 먹은 메뉴, 서비스, 동행자 반응, 아쉬운 점.
3. **남들 후기와 비교**: 다른 블로거들이 말한 포인트 칩을
   - 한 번 누르면 **나도 그랬음**
   - 두 번 누르면 **나는 달랐음**
   - 세 번 누르면 해제
4. **사진 순서대로 메모**: 갤러리를 처음부터 넘기며 사진마다 떠오르는 걸 적어요.
5. **MD 복사 / .md 다운로드**: 정리된 메모를 AI 채팅창에 붙여넣거나 파일로 받아요.

## MD에 들어가는 것
- 내가 누르고 적은 것만 "내 경험"으로 들어가요.
- 플레이스 정보는 "업체 기본 정보 (내 경험 아님)"으로 따로 표시돼요.
- 참고한 블로그는 링크만 남아요(내용은 복사하지 않아요).

## 개인정보
- 입력한 내용은 내 브라우저(이 기기)에만 저장돼요. 서버로 보내지 않아요.
- 링크 `#` 뒤의 데이터는 GitHub 서버로 전송되지 않아요.
